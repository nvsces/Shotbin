```

```
Обязательное поле. Страница обсуждений в репозитории подходит: она открыта,
не требует сервера и позволяет пользователю написать о проблеме.

**Маркетинг (URL)**
```

```


**Авторские права**
```

```
Формат: год первой публикации и имя правообладателя, без слова Copyright
и без значка ©, Apple добавляет их сам.

ПРОВЕРИТЬ: здесь должно стоять то же имя, что указано владельцем аккаунта
в App Store Connect. Если аккаунт оформлен на организацию — название организации.

- Возрастной рейтинг: 4+.
- App Privacy: «Data Not Collected» по всем пунктам.
- Снимки экрана: `screenshots/en` и `screenshots/ru`, размер 1284×2778.
